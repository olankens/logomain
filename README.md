### GATHER THE LOGOS

```sh
deposit=".assets" && mkdir -p "$deposit"
baseurl="https://github.com/olankens/logomain/raw/HEAD/source"
for f in {angular,chromium,kotlin,kubernetes,spring}; do
  curl -Lo "$deposit/logo-$f.svg" "$baseurl/$f.svg"
done
```
